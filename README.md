# Eid Al Itihad | عيد الاتحاد

A Unity WebGL game for UAE National Day, playable in the browser.

**Play:** https://ahmed-078.github.io/eid-etihad-game/

## Updating the game
1. Build for WebGL in Unity (keep Compression Format = Brotli and Decompression Fallback on).
2. Replace the files in `Build/` with the new ones.
3. If the build name changed, update `buildName` in `game.config.js`.
4. Commit and push. GitHub Pages redeploys automatically.
